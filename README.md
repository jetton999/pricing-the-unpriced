# Pricing the Unpriced — Sample Data Package
**NYU CUSP Capstone 2026–2027 · Sponsor: BNBD / Oxcart Assembly**


Project idea 1:

Use deep historic data to find the best and highest use for an assemblage of properties.
Use the historical record to keep new proposed uses anchored in the real heritage of the address and neighborhood.
Example: a historic movie theatre turned into a Live Entertainment Concert Hall.
For proposed uses, find competitive market examples to estimate economic performance
Harmonize uses across the neighborhood (dont over-saturate an assemblage with proposed uses to the point that they are non-competitive).


Project idea 2:

Research a worker-owned style exit for an Real Estate Investment Trust. Rather than a REIT exiting to a large institutional partner (aka selling out), figure out an economic arrangement by which tenants of the REIT can buy out or otherwise take control of the real estate while still compensating the REIT investors.
