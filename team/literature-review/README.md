# Systematic literature review (draft)

Draft systematic literature review for the fall 2026 CUSP deliverable (draft due 11 November 2026).

| File | What |
|---|---|
| `Literature_Review_Draft.pdf` | The review as submitted for the draft deadline |
| `Literature_Review_Draft.docx` | Editable copy of the same text |

Four review questions: heritage and property value; trade areas, agglomeration and tenant mix;
vacancy, revitalization and commercial viability; and the 1940 and 1970s Waverly programmes as a
precedent case. Section 7 maps each gap in the literature to the project's method.

Figures marked *[annotation]* come only from the sponsor's reading list and are to be checked
against the original publications. Appendix A lists how deeply each source was read. AI use is
disclosed in Appendix B.
